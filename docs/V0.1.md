# Places V0.1 product specification

## Goal
Build a personal iPhone test version that validates place discovery, saving and organization before building the social network.

## Navigation
`Feed | Explore | Add | My Places | Profile`

## Feed
Image-first two-column discovery experience. Cards prioritize photography, place name, short caption and save action. The visual direction can be inspired by Chinese image-first social discovery products while remaining an original Places interface.

## My Places
Personal library presented primarily with square 1:1 cards.

Supported filtering:
- Type
- Country
- City
- Status: Visited / Want to go
- Price: 1-4
- Personal rating: 0-5
- Tags

Search should eventually include place names and personal notes.

## Personal place metadata
The relationship between the test user and a Place contains:
- Visited or Want to go
- Personal rating
- Price level
- Personal note/comment
- Custom tags
- Custom lists

## Lists
Users can create arbitrary named lists. One place can be included in multiple lists. Lists should eventually display automatically generated covers based on their places.

## Testing mode
V0.1 is single-user. Public signup and approval onboarding are not needed for the first test build. Data structures should nevertheless avoid assumptions that would make multi-user support difficult later.

## Future social layer
Deferred features include public accounts, following, comments, likes, notifications, recommendations, moderation and richer social profiles.
